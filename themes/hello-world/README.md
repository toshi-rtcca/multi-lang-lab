# Hello World

## Task
Display the string "Hello, world!" on a text console.

Inspired by [Hello world/Text from Rosseta Code](https://rosettacode.org/wiki/Hello_world/Text)

## Language Comparison

| Feature | Python | TypeScript | Go | Rust |
|---------|--------|------------|-----|------|
| Main file | `src/hello_world/main.py` | `src/main.ts` | `main.go` | `src/main.rs` |
| Console output | `print()` | `console.log()` | `fmt.Println()` | `println!()` |
| Test location | `tests/` directory | `tests/` directory | `*_test.go` suffix | Inline `#[cfg(test)]` |
| Test framework | pytest | bun:test | testing (stdlib) | Built-in |
| Output capture | `capsys` fixture | `spyOn()` mock | `os.Pipe()` | Integration test |
