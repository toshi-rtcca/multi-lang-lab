# reverse-string (TypeScript)

Reverse a string at the grapheme cluster level using `Intl.Segmenter`.

## Usage

```bash
bun run src/main.ts <input-string>
```

## Run

```bash
bun install
bun run src/main.ts "asdf"
```

## Test

```bash
bun test
```
