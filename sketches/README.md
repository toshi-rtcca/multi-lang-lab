# Sketches

Quick experiments to explore an idea before (or instead of) turning it into a theme.

## Rules

- One directory per sketch: `sketches/{yyyymmdd}-{topic}/` (e.g. `20261024-http-get/`)
- One or two languages (usually Python or Rust)
- A single source file with inline tests is enough; no spec, README, fixtures, Makefile, or Dockerfile required
- An optional `NOTES.md` may record what was learned
- Commit directly or via a single small PR

## Promoting to a theme

If a sketch is worth comparing across languages, open a "New Theme" issue
(`.github/ISSUE_TEMPLATE/new-theme.md`) that links to the sketch.
